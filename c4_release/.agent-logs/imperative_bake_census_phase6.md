Generated by `c4_release/tools/census_imperative_bakes.py`.

Each op is classified by running its `bake_fn` against a fresh
`StubBlock` (or `StubModel` for `kind="model"`) and counting non-zero
cells written into the standard parameter tensors
(`attn.W_{q,k,v,o}`, `attn.alibi_slopes`, `ffn.W_{up,gate,down}`,
`ffn.b_{up,gate,down}`, plus `model.embed.embed.weight` /
`model.head.{weight,bias}` for model-kind ops).

AND the `bake_fn` source contains a `lower_ffn` / `lower_attention` /
`_lower_*_via_compiler_ir` call AND no direct `W_*.data[...]` writes.
