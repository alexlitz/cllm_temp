# Wave B — Cluster 3: L9 hi/lo CMP + add/sub hi_nibble + BP+8 shift

Migration plan for the 5 L9 position-role violations enumerated by
`tools/lint_position_role.py` (commit 199479f4). All entries are
``COMPUTE`` rules that currently gate on ``MARK_AX`` (one on
``MARK_BP/SP/PC``) and must move to ``MARK_SE_ONLY``.

Refer to ``docs/STEP_END_MIGRATION_TEMPLATE.md`` for the per-row 6-step
recipe.
